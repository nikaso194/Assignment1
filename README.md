Overview of Finger Counting Using ESP32-CAM
Finger counting using the ESP32-CAM is a computer vision project that detects and counts raised fingers using a camera. The ESP32-CAM captures images of a hand, which are processed using an image-recognition algorithm to determine the number of fingers raised, from zero to five, and left or right
